# ICF App - React с PrimeReact

Базовое приложение React с использованием библиотеки PrimeReact для создания современного пользовательского интерфейса.

## 🚀 Возможности

- **React 18** - современная версия React
- **PrimeReact** - богатая библиотека UI компонентов
- **PrimeFlex** - утилитарные CSS классы для flexbox
- **PrimeIcons** - иконки для интерфейса
- **Vite** - быстрый сборщик модулей
- **ES Modules** - современный стандарт модулей

## 📦 Установка

1. Установите зависимости:
```bash
npm install
```

## 🛠️ Запуск

### Режим разработки
```bash
npm run dev
# или
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

### Сборка для продакшена
```bash
npm run build
```

### Предварительный просмотр продакшен сборки
```bash
npm run preview
```

## 🔧 Настройка

### Добавление новых компонентов

1. Импортируйте нужный компонент из PrimeReact:
```jsx
import { ComponentName } from 'primereact/componentname';
```

2. Используйте в вашем JSX:
```jsx
<ComponentName prop="value" />
```

### Стилизация

- Используйте PrimeFlex классы для быстрой стилизации
- Добавляйте кастомные стили в `src/App.css`
- Подключайте дополнительные темы PrimeReact

### Темы

По умолчанию используется тема `lara-light-blue`. Для смены темы измените импорт в `src/App.jsx`:

```jsx
import 'primereact/resources/themes/your-theme/theme.css';
```

## ⚡ Преимущества Vite

- **Мгновенный запуск** - сервер разработки запускается за секунды
- **Быстрая HMR** - горячая перезагрузка модулей
- **Оптимизированная сборка** - использует Rollup для продакшена
- **ES Modules** - нативная поддержка современных модулей
- **TypeScript из коробки** - без дополнительной настройки
