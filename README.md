# Генератор HTML файлов с новостными статьями

## Описание

Проект для автоматической генерации HTML файлов с новостными статьями с TechCrunch за 2025 год. Код организован в модульную структуру для удобства чтения и поддержки.

## Структура проекта

```
Sand_Box/
├── index.js                    # Основной файл с функцией main
├── utils/                      # Папка с модулями
│   ├── folderManager.js        # Управление папками
│   ├── httpClient.js           # HTTP запросы
│   ├── htmlParser.js           # Парсинг HTML и извлечение ссылок
│   ├── newsFilter.js           # Фильтрация новостей по году
│   ├── articleProcessor.js     # Обработка и извлечение текста статей
│   ├── htmlGenerator.js        # Генерация HTML файлов
│   ├── articleSaver.js         # Сохранение статей
│   ├── newsGenerator.js        # Основная логика генерации новостей
│   ├── database.js             # Управление базой данных SQLite
│   └── dbManager.js            # Менеджер базы данных
├── news/                       # Папка с HTML файлами статей
├── img_test/                   # Папка для изображений
├── news_articles.db            # База данных SQLite
├── package.json                # Зависимости
├── README.md                   # Этот файл
├── API.md                      # Документация API
├── db-cli.js                   # CLI для работы с БД
└── example-usage.js            # Примеры использования
```

## Основной файл

`index.js` - содержит только функцию `main()` и импортирует все необходимые модули.

## Модули

### `utils/folderManager.js`

- `ensureImgTestFolder()` - создает папку `img_test`
- `ensureNewsFolder()` - создает папку `news`

### `utils/httpClient.js`

- `fetchPage(url)` - получает HTML страницу по URL

### `utils/htmlParser.js`

- `parseLinksFromHTML(html)` - извлекает ссылки из HTML

### `utils/newsFilter.js`

- `findFreshNewsByYear(links, year)` - фильтрует новости по году

### `utils/articleProcessor.js`

- `extractArticleText(html)` - извлекает текст статьи

### `utils/htmlGenerator.js`

- `createArticleHTML(title, content, url)` - создает HTML файл

### `utils/articleSaver.js`

- `saveArticle()` - сохраняет одну статью
- `saveAllArticles()` - сохраняет все статьи

### `utils/newsGenerator.js`

- `generateNewsArticles()` - основная логика генерации

### `utils/database.js`

- `Database` - класс для работы с SQLite базой данных
- `init()` - инициализация подключения и создание таблиц
- `saveArticle()` - сохранение статьи в БД
- `getAllArticles()` - получение всех статей
- `getArticleById()` - получение статьи по ID
- `deleteArticle()` - удаление статьи
- `getStatistics()` - получение статистики

### `utils/dbManager.js`

- `DatabaseManager` - менеджер для работы с БД
- `searchArticles()` - поиск статей
- `getArticlesByDateRange()` - получение статей за период
- `getTopArticlesByWordCount()` - топ статей по количеству слов
- `updateArticle()` - обновление статьи

## Запуск

### Основное приложение

```bash
npm start
# или
node index.js
```

### CLI для работы с базой данных

```bash
# Показать все статьи
npm run db list
# или
node db-cli.js list

# Показать статью по ID
npm run db show 1

# Поиск статей
npm run db search "AI"

# Показать статистику
npm run db stats

# Топ статей по количеству слов
npm run db top 5

# Удалить статью
npm run db delete 1

# Показать справку
npm run db help
```

### Пример использования API

```bash
npm run example
# или
node example-usage.js
```

## Что происходит при запуске

1. ✅ Инициализируется база данных SQLite
2. ✅ Создаются таблицы для статей и метаданных
3. ✅ Создается папка `img_test` (если не существует)
4. ✅ Получаются ссылки с TechCrunch
5. ✅ Ищутся новости 2025 года
6. ✅ Создается папка `news` (если не существует)
7. ✅ Каждая новость сохраняется в отдельный HTML файл И в базу данных
8. ✅ Показывается статистика по базе данных

## Результат

- Папка `news/` с HTML файлами статей
- База данных SQLite `news_articles.db` с полной информацией о статьях
- Каждый HTML файл содержит:
  - Заголовок статьи
  - Полный текст статьи
  - Ссылку на источник
  - Красивый дизайн
- База данных содержит:
  - Полную информацию о статьях
  - Метаданные (количество слов, даты создания/обновления)
  - Возможность поиска и фильтрации

## Новые возможности с SQLite

- 💾 **Персистентное хранение** - все статьи сохраняются в базе данных
- 🔍 **Поиск и фильтрация** - быстрый поиск по заголовкам и содержимому
- 📊 **Статистика** - детальная статистика по статьям
- 🚫 **Избежание дублирования** - проверка на существующие статьи
- 🛠️ **CLI интерфейс** - удобное управление базой данных из командной строки
- 📈 **Аналитика** - топ статей по количеству слов, фильтрация по датам

## Преимущества модульной структуры

- 🧩 **Читаемость** - каждый модуль отвечает за свою задачу
- 🔧 **Поддерживаемость** - легко найти и изменить нужную функциональность
- 🧪 **Тестируемость** - можно тестировать модули по отдельности
- 📚 **Переиспользование** - модули можно использовать в других проектах
- 🚀 **Масштабируемость** - легко добавлять новые функции
