# Настройка Telegram бота для отправки новостей

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например: "News Bot")
4. Введите username для бота (например: "my_news_bot")
5. Скопируйте полученный токен бота

## Шаг 2: Создание канала

1. Создайте новый канал в Telegram
2. Добавьте вашего бота в канал как администратора
3. Дайте боту права на отправку сообщений
4. Скопируйте username канала (например: @my_news_channel)

## Шаг 3: Настройка переменных окружения

1. Создайте файл `.env` в корне проекта (скопируйте из `.env.example`)
2. Заполните переменные:

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHANNEL_ID=@my_news_channel
```

## Шаг 4: Установка зависимостей

```bash
npm install
```

## Шаг 5: Использование

### Автоматическая отправка при извлечении новостей

По умолчанию новости автоматически отправляются в Telegram канал после извлечения:

```bash
npm start
```

### Отправка существующих новостей

Отправить последние 10 статей:

```bash
npm run db telegram
```

Отправить последние 5 статей:

```bash
npm run db telegram 5
```

### Отключение автоматической отправки

Если вы хотите отключить автоматическую отправку в Telegram, измените параметр в `utils/articleSaver.js`:

```javascript
await saveAllArticles(news2025, 'news', false); // false = не отправлять в Telegram
```

## Возможные проблемы

### Ошибка "TELEGRAM_BOT_TOKEN не найден"

- Убедитесь, что файл `.env` создан и содержит правильный токен
- Проверьте, что токен скопирован полностью

### Ошибка "TELEGRAM_CHANNEL_ID не найден"

- Убедитесь, что в `.env` указан правильный username канала
- Username должен начинаться с @ (например: @my_channel)

### Ошибка "Forbidden: bot is not a member of the channel chat"

- Добавьте бота в канал как администратора
- Дайте боту права на отправку сообщений

### Ошибка "Forbidden: bot was blocked by the user"

- Убедитесь, что бот не заблокирован в канале
- Проверьте права администратора бота

## Формат сообщений

Новости отправляются в следующем формате:

```
📰 Заголовок новости

Содержимое статьи (первые 2000 символов)...

🔗 Читать полностью
📅 01.01.2025
```

## Лимиты Telegram API

- Максимум 30 сообщений в секунду
- Максимум 4096 символов в сообщении
- Между отправками добавлена задержка в 1 секунду
