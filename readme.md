## O(n) - линейная сложность

Проход по всему массиву. Оценивает скорость с которой растет выполнение функции (алгоритма) в зависимости от количества поступающих в функцию данных

## O(1) - константная сложность

Обращение к элементу массива по индексу

## O(log₂(n)) - логорифмическая сложность

Бинарный поиск

Логарифмическая сложность — это когда ты делишь проблему пополам на каждом шаге, и потому решаешь её очень быстро, даже если данных много.

Если было 100 чисел, после каждого шага остаётся:

Шаг 1: 100 → 50

Шаг 2: 50 → 25

Шаг 3: 25 → 12

Шаг 4: 12 → 6

Шаг 5: 6 → 3

Шаг 6: 3 → 1

Ты сделал около 7 шагов, а не 100.

или log₂(100) = 7, где 7 это степень в которую нужно возмести 2 чтобы покрыть 100 чисел

## O(n**2) квадратичная сложность

Цикл в цикле. Сортировка выбором

## O(n*log₂(n))

Метод sort в js. То есть для каждого элемента массива осуществляется бинарный поиск

## O(2**n) Рекурсивный подсчет Фибоначчи

Сложность обратная O(log₂(n)), то есть количество вхождений возводится в степень 2
